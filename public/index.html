LOCAL FIRST
From setup to your first level.

        
1
Install the game
Full Geometry Dash on Steam, version 2.209 or later with native import. Geode is not required for this route.
Record actual game completion separately from proxy outcomes.

        
2
Connect a model
Ollama runs local models. We use Qwen3.5 from the course model family. Install Ollama and download the model:
ollama pull qwen3.5:4b
If the server is not running:
ollama serve
The app defaults to 4B; the final study also used 9B Q4_K_M. Choose a model that fits your memory.

        
3
Start DashLab
Requires Node.js 22+. In the project folder:
npm start
Open 127.0.0.1:4173. No additional npm packages are needed. Configure the model through OLLAMA_MODEL in .env.

        
4
Import and play
Download .gdlvl. In the game, open the created-levels editor and use file import. Select the map, inspect its objects and play it.
Then record the outcome, deaths and problem location in DashLab. The next repair can receive this human feedback.
The button location depends on the game version. Check import and completion for each new map.
