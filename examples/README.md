# Examples and regression fixtures

`recorded-repairs/` contains M01–M04: actual final-study outputs, native `.gdlvl`/`.gmd` exports, the initial geometry, and complete replay records. The chosen examples illustrate repairs after the outcomes were known. They are not new evaluation cases.

`briefs-retained.json` is the final numeric task bank; its exact original version is also captured under the recorded study's `sources/examples/`. `briefs-sectioned.json` supports compiler and assembly regression tests. `starter.json` is a simple application example.

The `routes/`, `accuracy/`, `branch-playable/`, `coins/`, and `sectioned-demo/` directories contain regression fixtures for optional application features. Their original descriptive text is retained. They are not mixed into the final 288-chain results. Some fixture reports precede the later native-game self-report; the current evidence statement is in [limitations](../docs/limitations.md).
